# OpenSwipe v0.6.1-1

> **Installed before 30 October 2026 (older than version 0.5.1-1)?** Install it once more from the
> [README](../../README.md#install). Older versions can't find updates after the move to the new name. After that it
> updates itself.

[Downloads](https://github.com/itsdestin/openswipe/releases/tag/v0.6.1-1) · Install steps: [README](../../README.md#install). Full list of changes: [CHANGELOG](../../CHANGELOG.md).

Two fixes reported by people using OpenSwipe. Typing and word choice are the same as 0.6.0.

## What changed

- **No pause when you come back from the symbols page or turn the screen.** The keyboard reloaded its whole word list
  every time; on phones that froze it for several seconds. It now keeps the list ready
  ([#24](https://github.com/itsdestin/openswipe/issues/24), with the ideas from
  [#25](https://github.com/itsdestin/openswipe/pull/25)).
- **`swipe-keyboard enable` works after choosing OpenSwipe in System Settings.** It refused with "Unsupported user
  KConfig syntax", because of the way System Settings saves its choice; people moving up from the Flatpak hit the
  same message. Now it turns on, and `disable` switches back to KDE's own keyboard
  ([#27](https://github.com/itsdestin/openswipe/issues/27)).
- **Older KDE parts:** setup no longer stops when KDE's window manager is older than 6.7 (it has no keyboard
  visibility setting yet; your setting is then left alone, and `--always-available` explains that it needs 6.7).
  Built from source, setup also accepts Plasma Keyboard 6.6; reported working on postmarketOS, not tested by us.

## What to know before upgrading

- Installed 0.6.0-1? Nothing to do: it updates itself, Steam Decks included.
- The packages themselves still need Plasma Keyboard 6.7 or newer; older KDE systems keep using the Flatpak.
